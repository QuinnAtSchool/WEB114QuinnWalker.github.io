What is the purpose of a function?

The purpose of a function is to simplify code for the purposes of reuse and usability. You could make a main that runs all the code for a program, but its probably not the best idea. Your code will be really long and complex (becuse its all in one function instead of seperated by use) , it will be challenging to test, and you wont be able to easily reuse your code if you run into a simular use case.

A function performs a task with input parameters, then returns a return value.
